# Assignment 5. JavaScript Basics (DOM Manipulation & Events)

**Student:** Ramazan Sagyngali
**Group:** SE-2524

## Description

A multi-page website with JavaScript exercises: variables and operators, DOM manipulation, mouse and keyboard events, a calculator, and a mini to-do application. All pages share one navigation bar.

## Pages

| Task   | Page       | Description                                                           |
| ------ | ---------- | --------------------------------------------------------------------- |
| Task 0 | index.html | First script: console.log and alert                                   |
| Task 1 | task1.html | Variables, data types, arithmetic operators, string concatenation     |
| Task 2 | task2.html | Changing paragraph text on button click                               |
| Task 3 | task3.html | Changing background color and font size of a block                    |
| Task 4 | task4.html | Adding and removing list items                                        |
| Task 5 | task5.html | Mouse events: mouseover and mouseout                                  |
| Task 6 | task6.html | Keyboard events: showing input value in real time (keyup)             |
| Task 7 | task7.html | Calculator: addition, subtraction, multiplication, division           |
| Task 8 | task8.html | To-do list: add, delete, mark as completed (tasks stored in an array) |

## Technologies

- HTML5
- JavaScript
- Bootstrap 5.3 via CDN (navigation bar)

## How to run

1. Clone the repository or download it as a ZIP.
2. Open index.html in a browser (an internet connection is needed to load Bootstrap from the CDN).
3. Use the navigation bar at the top to switch between tasks.
4. Open the browser console (F12) to see the output of Tasks 0 and 1.
